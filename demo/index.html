Capabilities

Everything You Need

FormGuard covers the most common form validation scenarios with a minimal API surface.

Email Validation

RFC-compliant email format checking. Detects invalid domains, missing @, and malformed addresses instantly.

FormGuard.isEmail('user@example.com')

Password Validation

Strength scoring with configurable rules: uppercase, lowercase, numbers, special characters, and minimum length.

FormGuard.passwordStrength('P@ss1')

Phone Validation

Validates international and local phone number formats. Strips spaces and dashes before checking.

FormGuard.isPhone('9876543210')

Custom Rules

Register your own validation logic with addRule(). Composable and reusable across your whole app.

FormGuard.addRule('username', fn, msg)

Schema Validation

Define a schema object and validate entire form payloads in one call. Perfect for API request validation.

FormGuard.validate(data, schema)
Documentation

Code Examples

Get up and running in seconds. Zero configuration required.

bash
npm install formguard-js
javascript
import FormGuard from 'formguard-js';

// Validate multiple fields at once
const result = FormGuard.validate({
  email: 'user@example.com',
  password: 'Hello@123',
  phone: '9876543210'
});
console.log(result);
// { valid: true, errors: {} }

// Individual validators
FormGuard.isEmail('test@gmail.com');
// { valid: true, error: null }

FormGuard.checkPassword('weak');
// { valid: false, error: 'Password must be at least 8 characters' }

FormGuard.passwordStrength('Hello@123');
// { strength: 'Strong', score: 6, checks: { ... } }
javascript
const schema = {
  email:    { required: true, type: 'email' },
  password: { required: true, type: 'password', minLength: 8 },
  phone:    { required: true, type: 'phone' }
};

const result = FormGuard.validate(formData, schema);
// { valid: false, errors: { email: 'Invalid email address' } }
javascript
// Register a custom rule
FormGuard.addRule(
  'username',
  (value) => /^[a-zA-Z0-9_]+$/.test(value),
  'Username must contain only letters, numbers, and underscores'
);

// Use the custom rule
const result = FormGuard.validateWith('john doe', 'username');
// { valid: false, error: 'Username must contain only letters...' }
